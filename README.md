# Java Networking Coursework

A collection of two distinct Java exercises retained in separate directories: `ПП` and `ПП2`. The second contains the RMI extension; source code and variants were not merged.

Java sources, course notes, and launch/compile scripts are included. ZIP archives and compiled `.class` files are excluded from this snapshot. Check course redistribution rules and review the scripts before public release. No compilation or tests were run.
