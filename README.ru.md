# Сетевое программирование на Java

[English version](README.md)

Коллекция двух связанных, но самостоятельных учебных работ по сетевому программированию. Каталоги не объединялись, чтобы сохранить исходные реализации и возможность их сравнения.

## Состав проектов

| Каталог | Содержание |
|---|---|
| `ПП/` | Чат на TCP-сокетах: клиент и сервер, типы сообщений, обработка протокола и командные скрипты запуска. |
| `ПП2/` | Расширенный вариант с интерфейсами Java RMI и отдельными реализациями клиента и сервера; исходный socket-вариант также сохранён. |

## Требования

- JDK 8 или новее — согласно инструкции, размещённой в проекте.
- Терминал или Java IDE.
- Для сетевого запуска сначала запускайте сервер, затем подключайте клиентов к выбранному адресу и порту.

## Сборка и запуск

В репозитории есть скрипты `.cmd` и `.sh`. Для macOS начните с инструкции `ПП/README_MACOS.md`, а для целевой ОС проверьте соответствующие скрипты в каталоге проекта. Для варианта RMI предусмотрены отдельные скрипты и policy-файлы.

Сборка и сетевой запуск в этой среде не проверялись. Команды, правила межсетевого экрана и поведение в сети следует проверить на целевой системе.

## Ограничения

Это учебные примеры сокетов, протокола сообщений, жизненного цикла клиента/сервера и RMI callback-механизмов, а не готовая к эксплуатации чат-платформа. Не следует предполагать наличие промышленной аутентификации, полноценной модели угроз или гарантий безопасного развёртывания.
